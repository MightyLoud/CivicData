# Colorado governed factory snapshots

`d329-co-factory-snapshot.json` is the D-329 read-only export input from `CO Jurisdiction Factory v0.1`.

The snapshot contains complete jurisdiction-scoped rows from Jurisdiction, Division, Body, Office, Person, RoleTerm, LeadershipRole, IdentifierCrosswalk, SourceEvidence, SourceAssertion, KnownGap, AddressTest, and QA for Akron, Alamosa, Alma, Arvada, and Aspen. Every row retains its source-sheet row number and the workbook values are stored without inference.

Aguilar, Antonito, and Arriba are excluded by contract. Regenerate only under a separately authorized factory-snapshot gate.
