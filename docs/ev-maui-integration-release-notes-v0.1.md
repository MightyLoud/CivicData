# Maui countywide Mayor/Council integration v0.1

This proposed release distributes the unchanged metadata manifest for Maui's
bounded Mayor/Council integration at commit
`2b3e8d5df11ed4f4b19f7579c9bd1663131070bf`.
The sole asset is `maui-mayor-council-integration-manifest-v0.1.json`:
5,596 bytes, SHA-256
`eb577b26a899f5e03bb6450225438bcbebd0efb3b53993e14426eddb8506683a`.

The manifest describes 10 offices, 10 holders, 9 residency areas, and 2 leadership
roles through identifiers, counts, hashes, review boundaries, and evidence links.
It contains no raw package archive or officeholder payload. All Council seats
apply countywide; residency requirements do not filter voters. The appointed
holder selection and the office's ordinary elected selection method are preserved.
Exact tenure intervals remain unresolved.

The manifest's `CANDIDATE_PUBLICATION_HELD` status and false authorization flags
record preparation. These certified bytes remain unchanged. Any actual metadata
distribution requires separate authority recorded in the execution receipt and
appended references; it does not change package publication eligibility or promote
the production catalog. This document is not execution approval.

Source acceptance expires October 12, 2026 UTC under the existing 30-day policy.
Execution requires a complete primary-source recheck no more than 24 hours old.
Retaining evidence does not extend either limit. Full Essentials, election results,
complete-jurisdiction coverage, and hosted delivery remain uncertified.
No public Maui endpoint, deployment, canonical replacement, or Kalawao work is claimed.
The existing Texas and Kauaʻi releases remain unchanged. This release is not
