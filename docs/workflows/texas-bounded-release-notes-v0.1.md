# Texas bounded legislative representation v0.1

This release exposes the governed **intersection of Texas House District 49 and Texas Senate District 14** through the bounded CivicData representation runtime.

## Included

- Texas House District 49 representation binding;
- Texas Senate District 14 representation binding;
- both bindings required atomically;
- authoritative current Person identities;
- governed legislative geometry with fail-closed boundary handling;
- public runtime endpoint: `https://texas-bounded-api-production.up.railway.app`.

## Not included

This release does **not** claim complete Texas legislative coverage, complete jurisdiction coverage, Full Essentials support, election coverage, or publication eligibility for the underlying raw/source package or registry layer.

The GitHub Release contains only the deterministic bounded-runtime release manifest. Raw package bytes are not release assets.

Canonical civic-data writes: **0**.
