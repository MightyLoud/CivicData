# Rights and Licensing

This repository contains a compilation of public-source civic records and record-level provenance.

## Current status

No package-level open-source or open-data license has been adopted yet. Absence of a license is intentional and must not be interpreted as permission to reuse every repository component without restriction.

Until a license is adopted:

- preserve every record-level source and attribution;
- review the terms of each upstream source;
- do not imply upstream endorsement;
- do not remove rights uncertainty from manifests or documentation;
- treat code and data licensing as potentially separate decisions.

Formal licensing remains a governance gate before broad public multi-jurisdiction distribution.
